1. 블루투스 연동 및 데이터 수신 방법
이 모듈은 투명 전송(Transparent Transmission, 透传) 모드를 지원합니다. 앱과 측색기가 연결되면, 앱에서 특정 명령을 보내고 측색기가 그 결과를 보낼 때 이 모듈이 중간에서 데이터를 그대로 전달해 주는 방식입니다.
데이터 전송 모드 설정 (AT+BY)
데이터를 주고받기 위해서는 모듈의 모드를 확인해야 합니다.
* 비투명 모드 (BY=00): AT+DA(문자열)나 AT+DH(16진수) 명령어를 통해서만 데이터를 보낼 수 있습니다.
* 투명 전송 모드 (BY=01): 연결이 확립되면 별도의 AT 명령 없이 UART를 통해 들어오는 모든 데이터를 블루투스로 즉시 전송합니다.
* 불완전 투명 전송 모드 (BY=02): 데이터 전송이 가능하며, 특정 탈출 코드를 통해 모드에서 빠져나올 수 있습니다.
연결 시 필요한 정보
* 서비스 UUID: 0000e0ff-3c17-d293-8e48-14fe2e4da212
* 기본 통신 속도(UART): 115200 bps (8 데이터 비트, 1 정지 비트, 패리티 없음)

1. 스캔 & 연결

주요 AT 명령어:
장치 검색:
* AT+SC - 주변 BLE 장치 스캔 시작/중지
* AT+IQ - 블루투스 장치 검색 시작/중지

장치 연결:
* AT+CT=<MAC주소> - 특정 MAC 주소로 연결
* 연결 성공 시: +CONNECTED >> 0x<MAC주소> 응답
연결 설정:
* AT+CN - 연결 파라미터 설정 (간격, 지연, 타임아웃)
* AT+UP - 연결 파라미터 업데이트

AT+EX     // 투명전송 모드 종료


수동 데이터 전송:
* AT+DA=<데이터> - 원시 데이터 전송
